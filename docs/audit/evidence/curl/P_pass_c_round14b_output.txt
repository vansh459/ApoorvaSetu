
================ 0. the exact README quickstart a newcomer follows ================
        1	---
        2	
        3	## Quick start
        4	
        5	Requirements: Node.js 20+ and npm.
        6	
        7	```bash
        8	npm install
        9	cp .env.example .env   # optional; demo mode runs with no configuration
       10	npm run dev            # http://localhost:5173
       11	```
       12	
       13	The app starts in **demo mode** with seeded institutions, applications, EVC visits, compliance
       14	records and documents — no backend required.
       15	
       16	### Run with Docker
       17	
       18	One container serves the built SPA, the Express back end and the assistant APIs on a single
       19	origin. Demo mode needs no `.env` and no database.
